# ♟ 야매체스

(예전 이름: ∂ 미분 배틀 · 저장소 이름 Partial-Differential-Equation-Game)

고3 수학 문제를 맞혀서 공격하고, 이동하고, 살아남는 **2~5인 턴제 보드게임**입니다. (5명이면 오각형 판)
한 기기에서 번갈아 하거나, 방 코드로 친구를 초대해 온라인으로 할 수 있습니다.

**게임 주소:** https://eukane.github.io/Partial-Differential-Equation-Game/
(이전 버전: [v2](https://eukane.github.io/Partial-Differential-Equation-Game/v2/) · [클래식](https://eukane.github.io/Partial-Differential-Equation-Game/classic/))

## 실행 방법

빌드가 필요 없는 정적 웹 페이지입니다. KaTeX가 `vendor/`에 포함되어 있어 한 기기 모드는 오프라인에서도 동작합니다.

```bash
# 방법 1: index.html 을 브라우저로 바로 열기 (한 기기 모드)
# 방법 2: 로컬 서버
python3 -m http.server 8000   # → http://localhost:8000
```

## 게임 규칙

- 2~4명은 8×8 체스판, **5명은 오각형 판**(11×11 격자 안의 정오각형, 83칸, 탄은 비스듬한 벽에서도 입사각대로 반사), 시작 체력은 게임 전에 100 / 150 / 200 / 300 중에서 고릅니다 (기본 150, 온라인은 방장이 대기실에서 선택). 시작 칸은 서로 같은 줄·대각선에 겹치지 않게 배치됩니다. 마지막까지 살아남은 사람이 승리합니다.
- 첫 차례에 **증강**(공격 스타일)을 무작위 3개 중 하나 골라 게임 끝까지 씁니다.
- 차례마다 **행동 선택 → 과목 선택 → 난이도 선택(기본 / 심화 / 🔥킬러) → 4지선다 문제**. 맞히면 행동 실행, 틀리거나 시간이 지나면 턴 종료.
- **조준은 무료**: 판 위의 칸을 누르면 그 칸을 조준하고, 5°·15° 단위로 미세 조정할 수 있습니다.
- 판 위에 지금 공격하면 닿는 경로·칸과 맞을 적(빨간 원)이 표시됩니다.

| 행동 | 설명 | 기본 | 심화 | 킬러 |
|---|---|---|---|---|
| ⚔️ 공격 | 고른 증강 스타일로 공격 | 스타일별 | 스타일별 | 심화 +12 |
| 👣 이동 | 킹처럼 가로·세로·대각선, 범위 안의 빈 칸을 눌러 이동 | 2칸 이내 | 3칸 이내 | 4칸 이내 |
| 🎁 랜덤박스 | 회복 +40 / 강화탄 (다음 공격의 첫 타격 ×1.5) / 번개 30 / 유성우 18 / 순간이동 +HP15 / 위치 교환 +15 피해 / 추가 행동 +HP10 / 💣 꽝 | 전체 | 꽝 없음 | 꽝 없음 + 효과 2개 |

### 모드

- **🎲 턴제** (한 기기 · 온라인): 항상 1번 → 2번 → … 순서대로 돌아갑니다. 1라운드는 **준비 라운드**라 공격할 수 없고(이동·랜덤박스·증강만), 추가 행동으로는 공격할 수 없습니다.
- **🔥 난전** (온라인 전용): 턴 없이 모두 동시에 문제를 풀고, 맞히는 대로 바로 행동합니다. 오답이면 10초 동안 쉬어요. 방장이 대기실에서 모드를 고릅니다.

### 🎵 배경음악

직접 작곡한 곡 두 가지 스타일 중에서 고를 수 있습니다 (시작 화면, 상단 버튼, ☰ 메뉴). 실제 악기 샘플(FluidR3 사운드폰트)로 녹음했습니다.

- **🎷 일렉트로스윙** (기본, A단조 148bpm, 한 바퀴 약 2분): 피콜로·신스의 고음 훅으로 시작해, 베이스가 한 박씩 A→G→F#→G# 로 걷는 드롭 위에서 색소폰·트럼펫이 '빠빰' 리프를 찍습니다. 드롭 → 색소폰 솔로 → **고음 하이라이트**(중저음을 덜어 내고 훅이 A6·C7 까지 치고 올라감) → 최고조 → 브레이크다운 → 드롭 B → 트럼펫 솔로 → 하이라이트 → 마지막 최고조. 합성 킥 레이어와 킥마다 출렁이는 사이드체인 펌핑, 8마디마다 '스톱' 뒤 '팡'.
- **🎺 오케스트라 록** (164bpm): 트럼펫·트롬본·호른·현악·팀파니·합창에 디스토션 기타·일렉 베이스·신스를 섞은 전투곡.
- **내 체력이 30% 이하**면 더 빠르고 긴박한 위기 테마로 바뀝니다. 온라인은 내 말 기준이라 다른 사람 차례가 되어도 곡이 바뀌지 않고, 한 기기 모드는 사람 플레이어 중 누구든 위험하면 위기 테마가 나옵니다 (AI 는 제외). 회복해서 30% 를 넘으면 원래 곡으로.
- 승부가 나면 승리 팡파르.

### 🔊 효과음과 소리 설정

효과음은 파일 없이 Web Audio 로 그때그때 합성합니다 (`js/sfx.js`).

- **게임 소리**: 공격 스타일 19가지마다 다른 타격음(저격 '탕', 산탄 '쾅', 박격포 휘파람+폭발, 레이저 '지잉', 체인 번개 '치지직', 부메랑 '휘익-휘익', 갈고리 '철컥-쉭' …, 말마다 음높이가 조금씩 다름), 캐릭터별 피격 목소리(🦊 깽 · 🐧 꽥 · 🐸 개굴 · 🐙 뽀록 · 🐤 삐약), 발소리, 나이트 도약·착지, 방패 막기, 회복, 탈락, 동전(앞면·뒷면), 랜덤박스 룰렛과 효과별 소리(강화탄 충전, 번개, 유성우, 순간이동, 위치 교환, 추가 행동, 폭탄).
- **시스템 소리**: 버튼 딸깍, 정답·오답·시간 초과, 빠른 정답 반짝, 마지막 5초 째깍, 내 차례 알림, 증강 선택.
- **🔊 버튼**(휴대폰은 ☰ 메뉴)을 누르면 **🎵 음악 · 🔔 시스템 · 💥 게임** 음량을 따로 조절하고 각각 끌 수 있습니다. `전체 음소거` 또는 `M` 키로 한 번에 끄기. 설정은 기억됩니다.

### 🤖 AI 플레이어

사람이 모자라면 빈 자리를 AI 로 채울 수 있습니다.

- **한 기기**: 시작 화면에서 자리마다 **👤 사람 / 🤖 AI** 를 눌러 바꿉니다 (기억됨). AI 차례에는 기기를 넘길 필요 없이 알아서 둡니다.
- **온라인**: 방장이 대기실 빈 자리에서 **🤖 AI 넣기** (✕ 로 빼기). 자리가 다 찼을 때 사람이 들어오면 AI 자리를 내줍니다. AI 는 방장 화면이 대신 두고, 사람의 행동과 똑같이 모두에게 전달됩니다. 턴제·난전 모두 됩니다 (난전에서는 오답이면 AI 도 10초 쉼).
- AI 도 문제를 풉니다: 난이도를 고르고 기본 85% · 심화 65% · 킬러 45% 확률로 맞힙니다. 맞히면 조준 각도·박격포 목표·나이트 착지 칸을 모두 따져 가장 많이 맞는 곳을 노리고, 닿는 적이 없으면 공격하기 좋은 칸으로 이동하며, 체력이 낮으면 거리를 벌리거나 랜덤박스를 엽니다.

### 🪙 동전 칸

판에 동전 칸이 3개 있습니다. 문제를 맞히고 그 칸으로 **이동**하면 동전을 던져, **앞면이면 살아 있는 모두의 위치가 무작위로 섞입니다.** 쓴 동전 칸은 다른 빈 칸으로 옮겨 갑니다.

### 🎲 직업 랜덤 모드
설정 화면(온라인은 방장 로비)의 **🎲 직업 랜덤**을 켜면 증강을 고르지 않고, 게임이 시작될 때 모두가 서로 다른 직업을 무작위로 받는다 (게임 seed 로 정해져 온라인 모든 화면이 같다).

### 🧪 실험 모드 (테스트 중)
설정 화면(온라인은 방장 로비)의 **🧪 실험 모드**를 켜면:
- **🪨 돌**: 탄을 막는다. 튕기는 탄(저격·도탄·난사)은 돌에 튕긴다. 말이 설 수 없다.
- **📦 상자**: 탄을 막고, 두 번 맞으면 부서진다. 부순 사람은 🛡️ 방패. 관통탄(저격·레이저·창·부메랑)은 상자를 부수며 지나간다. 칸 공격(킹·박격포·회오리…)도 상자를 친다.
- **⚡ 자기장**: 턴제는 5라운드부터 3라운드마다, 난전은 행동 24번째부터 16번마다 바깥 한 겹씩 좁혀 온다. 한 라운드 전(난전은 몇 행동 전)에 주황 점선으로 예고. 빨간 칸에 있으면 턴제는 라운드마다, 난전은 행동할 때마다 10 → 15 → 20 피해 (방패로 못 막음).
- 배치는 게임 seed 로 정해져 온라인에서도 모든 화면이 같다. 유도탄·체인 번개는 장애물을 무시한다.

### 점수와 빠른 정답 보너스

- 정답 점수 = 난이도 점수(기본 100 / 심화 200 / 킬러 300) + 속도 점수(남은 시간 비율 × 최대 100). 결과 화면에 점수 순위가 표시됩니다.
- **⚡ 빠른 정답**: 제한 시간의 1/3 안에(기본 15초, 심화 25초, 킬러 40초) 맞히면 공격 피해 +10, 이동 범위 +1칸, 랜덤박스 꽝 없음.
- 제한 시간: 기본 45초, 심화 75초, 킬러 120초. 시작 화면에서 끌 수 있습니다.

### 문제 범위 (4과목 × 3난이도, 154가지 유형, 모두 무작위 숫자)

- **기본**: 공식 하나로 풀리는 교과서·모의고사 유형.
- **심화**: 모의고사 수준. 한두 단계면 풀리는 가벼운 응용 (예: 넓이, 역함수 미분, 부분적분, 조건부확률, 벡터 사잇각).
- **🔥 킬러**: 2~3단계를 엮어야 풀리는 수능 상위권 유형. 대신 보상이 큽니다. 예: 매개변수 곡선의 접선 y절편, 역함수와 합성함수, 정적분으로 정의된 함수의 극값, 극댓값에서 극솟값 구하기, 베이즈 조건부확률, 이웃하지 않는 순열, 타원·쌍곡선과 직각삼각형, 벡터 크기의 최솟값, 포물선 초점현, 점과 평면 사이 거리, 닫힌구간의 최대·최소, 원점을 지나는 접선, 방정식의 실근의 개수, 빈 상자 없이 나누기, 원 위의 점과 내적.

- **📘 공통 (수학Ⅰ·Ⅱ)**: 지수·로그(부등식 포함), 삼각함수·부채꼴, 수열(등차·등비·∑·귀납적 정의), 다항함수의 극한(0/0 꼴)·연속·미분·평균값 정리·적분, 접선과 넓이, 속도와 위치, 미정계수, 미분가능성
- **∫ 미적분**: 지수·로그·삼각함수의 극한·미분·적분, 여러 가지 미분법(몫·합성·역함수·음함수·매개변수), 급수, 구분구적법, 치환·부분적분, 접선, 변곡점, 실근의 개수
- **🎲 확률과 통계**: 순열·조합·중복조합, 분배, 이항정리(상수항), 확률·조건부확률·독립사건·독립시행, 확률변수 aX+b, 이항분포, 정규분포
- **📐 기하**: 포물선(준선 포함)·타원·쌍곡선, 벡터의 연산·크기·내적·사잇각·정사영·삼각형 넓이, 공간좌표·공간벡터, 구, 정사영

## 온라인 사설방 (로그인 필요 없음)

1. 방장: 닉네임을 적고 **방 만들기** → 4자리 방 코드와 초대 링크가 나옵니다.
2. 친구: 초대 링크를 열면 바로 방에 들어갑니다 (닉네임은 자동으로 붙고, 로비에서 바꿀 수 있음).
3. 2~5명이 모이면 방장이 **게임 시작** (5명이면 오각형 판, 빈 자리는 🤖 AI 로 채울 수 있음). 자리가 찬 뒤 들어온 사람은 관전합니다. 각자 자기 기기에서 자기 차례에 문제를 풉니다.

- **관전**: 다른 사람 차례에는 그 사람이 고르는 과목·난이도, 문제, 남은 시간, 고른 답과 정답 여부, 조준 방향이 실시간으로 보입니다.
- 통신은 공개 MQTT 중계 서버(`public.cloud.shiftr.io`, 실패 시 `broker.hivemq.com`)를 거칩니다. 공개 서버이므로 닉네임에 개인정보를 넣지 마세요.
- 방장의 화면이 게임 상태의 기준입니다. 행동은 난수 seed와 함께 전달되어 모든 화면에서 같은 결과와 애니메이션이 재생됩니다.
- **방장 자동 이어받기**: 방장이 나가거나 앱을 내려 응답이 없어지면, 4초 뒤 자리 순서로 첫 번째 접속 중인 사람이 방장을 이어받아 게임이 계속됩니다. 대기실(시작 전)에서도 마찬가지라 남은 사람이 바로 시작할 수 있어요. 원래 방장이 돌아오면 자동으로 참가자가 되어 지금 상태를 그대로 받아 옵니다.
- **자리 비움 대신 두기** (턴제): 방을 떠난 사람의 차례는 2초 뒤, 화면만 내린 사람의 차례는 8초 뒤 AI 가 대신 둡니다 (한 번 대신 둔 자리는 돌아올 때까지 다음 차례도 바로). 기다리는 화면에 'N초 뒤 AI 가 대신'이 보입니다. 돌아오면 다시 직접 둘 수 있어요. (난전은 차례가 없으니 그냥 쉽니다)
- 모든 기기가 3초마다 '접속 중' 신호를 보내고, 화면을 내리면 바로 '자리 비움'으로 표시됩니다.
- 방장이 페이지를 완전히 닫고 아무도 남지 않았다면, 같은 기기에서 다시 열어 **진행 중이던 방 다시 열기**를 누르면 이어집니다.
- 클래식 버전 방과 새 버전 방은 서로 섞이지 않습니다.
