# ∂ 미분 배틀 (Partial Differential Equation Game)

미적분·편미분 문제를 맞혀서 공격하고, 이동하고, 살아남는 **1 vs 1 vs 1 턴제 보드게임**입니다.
한 기기에서 세 명이 번갈아 플레이하며, 차례가 되면 카메라가 그 플레이어의 시점(바라보는 방향이 화면 위쪽)으로 이동합니다.

## 실행 방법

빌드가 필요 없는 정적 웹 페이지입니다. KaTeX가 `vendor/`에 포함되어 있어 오프라인에서도 동작합니다.

```bash
# 방법 1: index.html 을 브라우저로 바로 열기
# 방법 2: 로컬 서버
python3 -m http.server 8000   # → http://localhost:8000
```

## 🧪 베타 버전

**베타 주소:** https://eukane.github.io/Partial-Differential-Equation-Game/beta/

안정 버전(위 게임 주소)은 그대로 두고, 바뀐 규칙은 `beta/` 폴더에서 따로 시험합니다. 두 화면의 시작 화면에 서로 오가는 링크가 있습니다.

- **자유 조준:** 방향이 8방위가 아니라 자유 각도입니다. 판 위의 칸을 누르면 그 칸을 조준하고, 5°·15° 단위로 미세 조정할 수 있습니다 (무료).
- **칸 골라 이동:** 킹처럼 가로·세로·대각선 어느 방향이든, 범위 안의 빈 칸을 눌러 이동합니다 (기본 2칸, 심화 3칸, ⚡ +1칸).
- **증강:** 첫 차례에 무작위 공격 스타일 3개 중 하나를 골라 게임 끝까지 씁니다. 저격 · 산탄 · 도탄 · 비숍 · 룩 · 나이트 · 킹 · 박격포 · 난사.
- 판 위에 지금 공격하면 닿는 경로·칸과 맞을 적(빨간 원)이 표시됩니다.
- 베타 온라인 방은 안정 버전 방과 섞이지 않습니다.

## 온라인 사설방 (로그인 필요 없음)

**게임 주소:** https://eukane.github.io/Partial-Differential-Equation-Game/

1. 방장: 위 주소를 열고 닉네임을 적은 뒤 **방 만들기** → 4자리 방 코드와 초대 링크가 나옵니다.
2. 친구: 초대 링크를 열면 코드가 자동으로 채워져 있습니다. 닉네임만 적고 **참가**. (계정·로그인 필요 없음)
3. 2~3명이 모이면 방장이 **게임 시작**. 각자 자기 기기에서 자기 차례에 문제를 풉니다.

- 통신은 공개 MQTT 중계 서버(`public.cloud.shiftr.io`, 실패 시 `broker.hivemq.com`)를 거칩니다. 공개 서버이므로 닉네임에 개인정보를 넣지 마세요.
- 방장의 화면이 게임 상태의 기준입니다. 행동은 난수 seed와 함께 전달되어 모든 화면에서 같은 결과와 애니메이션이 재생됩니다.
- 방장이 페이지를 닫으면 게임이 멈춥니다. 같은 기기에서 다시 열어 **진행 중이던 방 다시 열기**를 누르면 이어집니다.
- claude.ai 링크(https://claude.ai/artifact/2E2sjbN9FEvtqU8FMwpNie)에서 열면 claude.ai 자체의 실시간 기능을 씁니다 (이 경우 참가자도 claude.ai 로그인 필요).
- 로컬 파일(`index.html`)을 더블클릭해서 열면 한 기기 모드만 됩니다.

## 게임 규칙

- 8×8 체스판, 플레이어 3명, HP 100. 마지막까지 살아남은 사람이 승리합니다.
- 차례가 오면 **행동 선택 → 난이도 선택 → 4지선다 문제**. 맞히면 행동이 실행되고, 틀리거나 시간이 지나면 턴이 끝납니다.
- 방향은 8방위(45° 단위)입니다.

| 행동 | 설명 | 기본 | 심화 |
|---|---|---|---|
| 🎲 난사 | 무작위 좌표를 향해 발사. 벽에 3번 반사되며, **관통탄**이라 맞혀도 사라지지 않고 경로상의 모두에게 피해 (한 발당 1인 1회). 튕긴 탄에 **자신도** 맞을 수 있음 | 피해 25 | 피해 35 |
| 🎯 조준 사격 | 바라보는 방향으로 직선 발사, 처음 맞는 플레이어에게 피해 | 피해 20 | 피해 30 |
| 👣 이동 | 바라보는 방향으로 이동. 벽에 닿으면 반사. 다른 플레이어와 부딪히면 멈추고 상대에게 10 피해 | 1~3칸 | 1~5칸 |
| 🎁 랜덤박스 | 회복 / 방패 / 강화탄 / 번개 / 유성우 / 순간이동 / 위치 교환 / 추가 행동 / 💣 꽝 | 전체 | 꽝 없음 |
| 🔄 시점 전환 | 45° 단위로 방향 전환 | 무료 (문제 없음) | |

제한 시간: 기본 45초, 심화 90초. 시작 화면에서 끌 수 있습니다.

### 점수와 빠른 정답 보너스

- 정답 점수 = 난이도 점수(기본 100 / 심화 200) + 속도 점수(남은 시간 비율 × 최대 100). 결과 화면에 점수 순위가 표시됩니다.
- **⚡ 빠른 정답**: 제한 시간의 1/3 안에(기본 15초, 심화 30초) 맞히면 그 행동이 강화됩니다. 사격 피해 +10, 이동 최대 거리 +1칸, 랜덤박스 꽝 없음.

### 문제 범위 (모두 무작위 숫자로 생성)

- **기본 (고3)**: 미분계수, 극한, 합성함수·곱·로그함수의 미분, 이계도함수, 정적분, 극값, 접선, 삼각함수 합성
- **심화 (고3 상위권 · 수능 미적분 킬러 유형)**: 미정계수 극한, 역함수·음함수·매개변수 미분, 정적분으로 정의된 함수, e의 정의, 등비급수, 수열의 극한, 정적분과 넓이, 치환·부분적분, 변곡점, 삼각함수의 극한, 미분가능성

### 단축키

| 키 | 동작 |
|---|---|
| `1`–`4` | 보기 선택 |
| `1` / `2` | 난이도 선택 (기본/심화) |
| `←` `→` | 시점 전환 |
| `V` | 플레이어 시점 ↔ 전체 보기 |
