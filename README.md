# ∂ 미분 배틀 (Partial Differential Equation Game)

고3 수학 문제를 맞혀서 공격하고, 이동하고, 살아남는 **1 vs 1 vs 1 턴제 보드게임**입니다.
한 기기에서 번갈아 하거나, 방 코드로 친구를 초대해 온라인으로 할 수 있습니다.

**게임 주소:** https://eukane.github.io/Partial-Differential-Equation-Game/
(이전 규칙: https://eukane.github.io/Partial-Differential-Equation-Game/classic/)

## 실행 방법

빌드가 필요 없는 정적 웹 페이지입니다. KaTeX가 `vendor/`에 포함되어 있어 한 기기 모드는 오프라인에서도 동작합니다.

```bash
# 방법 1: index.html 을 브라우저로 바로 열기 (한 기기 모드)
# 방법 2: 로컬 서버
python3 -m http.server 8000   # → http://localhost:8000
```

## 게임 규칙

- 8×8 체스판, 플레이어 2~3명, HP 120. 마지막까지 살아남은 사람이 승리합니다.
- 첫 차례에 **증강**(공격 스타일)을 무작위 3개 중 하나 골라 게임 끝까지 씁니다.
- 차례마다 **행동 선택 → 과목 선택 → 난이도 선택 → 4지선다 문제**. 맞히면 행동 실행, 틀리거나 시간이 지나면 턴 종료.
- **조준은 무료**: 판 위의 칸을 누르면 그 칸을 조준하고, 5°·15° 단위로 미세 조정할 수 있습니다.
- 판 위에 지금 공격하면 닿는 경로·칸과 맞을 적(빨간 원)이 표시됩니다.

| 행동 | 설명 | 기본 | 심화 |
|---|---|---|---|
| ⚔️ 공격 | 고른 증강 스타일로 공격 | 스타일별 | 스타일별 |
| 👣 이동 | 킹처럼 가로·세로·대각선, 범위 안의 빈 칸을 눌러 이동 | 2칸 이내 | 3칸 이내 |
| 🎁 랜덤박스 | 회복 / 방패 / 강화탄 / 번개 / 유성우 / 순간이동 / 위치 교환 / 추가 행동 / 💣 꽝 | 전체 | 꽝 없음 |

### 증강 (공격 스타일)

| 스타일 | 설명 | 기본 | 심화 |
|---|---|---|---|
| 🎯 저격 | 조준 방향 직선, 처음 맞는 적 | 30 | 40 |
| 💥 산탄 | 조준 방향 ±20° 세 갈래, 사거리 4칸 (겹치면 누적) | 15 | 20 |
| 🌀 도탄 | 조준 방향, 벽 3번 반사 · 관통 (자신도 맞을 수 있음) | 20 | 28 |
| ✖️ 비숍 | 대각선 4방향 동시 발사 | 20 | 28 |
| ➕ 룩 | 가로·세로 4방향 동시 발사 | 20 | 28 |
| 🐴 나이트 | 나이트 이동 칸(L자) 8곳 동시 타격 | 30 | 40 |
| 👑 킹 | 주변 8칸 강타 | 35 | 45 |
| 💣 박격포 | 5칸 안의 칸을 골라 3×3 폭발 (가장자리 60%, 자신 포함) | 25 | 35 |
| 🎲 난사 | 무작위 좌표로 발사, 벽 3번 반사 · 관통 | 30 | 40 |

### 밸런스 (선공 이점 완화)

- **1라운드는 준비 라운드**: 공격할 수 없고 이동·랜덤박스·증강만 가능합니다 (랜덤박스의 번개·유성우도 나오지 않음).
- **라운드마다 시작 순서가 한 칸씩 돌아갑니다**: A B C → B C A → C A B.
- 강화탄은 1.5배, 추가 행동으로는 공격할 수 없습니다.

### 점수와 빠른 정답 보너스

- 정답 점수 = 난이도 점수(기본 100 / 심화 200) + 속도 점수(남은 시간 비율 × 최대 100). 결과 화면에 점수 순위가 표시됩니다.
- **⚡ 빠른 정답**: 제한 시간의 1/3 안에(기본 15초, 심화 30초) 맞히면 공격 피해 +10, 이동 범위 +1칸, 랜덤박스 꽝 없음.
- 제한 시간: 기본 45초, 심화 90초. 시작 화면에서 끌 수 있습니다.

### 문제 범위 (4과목 × 2난이도, 63가지 유형, 모두 무작위 숫자)

- **📘 공통 (수학Ⅰ·Ⅱ)**: 지수·로그, 삼각함수, 수열(등차·등비·∑·귀납적 정의), 다항함수의 극한·미분·적분, 미정계수, 미분가능성
- **∫ 미적분**: 여러 가지 함수의 극한·미분(몫·합성·역함수·음함수·매개변수), 급수, 치환·부분적분, 변곡점
- **🎲 확률과 통계**: 순열·조합·중복조합, 이항정리, 확률·조건부확률·독립시행, 이항분포, 정규분포
- **📐 기하**: 포물선·타원·쌍곡선, 벡터의 크기·내적·사잇각, 공간좌표, 구, 정사영

## 온라인 사설방 (로그인 필요 없음)

1. 방장: 닉네임을 적고 **방 만들기** → 4자리 방 코드와 초대 링크가 나옵니다.
2. 친구: 초대 링크를 열면 코드가 자동으로 채워져 있습니다. 닉네임만 적고 **참가**.
3. 2~3명이 모이면 방장이 **게임 시작**. 각자 자기 기기에서 자기 차례에 문제를 풉니다.

- **관전**: 다른 사람 차례에는 그 사람이 고르는 과목·난이도, 문제, 남은 시간, 고른 답과 정답 여부, 조준 방향이 실시간으로 보입니다.
- 통신은 공개 MQTT 중계 서버(`public.cloud.shiftr.io`, 실패 시 `broker.hivemq.com`)를 거칩니다. 공개 서버이므로 닉네임에 개인정보를 넣지 마세요.
- 방장의 화면이 게임 상태의 기준입니다. 행동은 난수 seed와 함께 전달되어 모든 화면에서 같은 결과와 애니메이션이 재생됩니다.
- 방장이 페이지를 닫으면 게임이 멈춥니다. 같은 기기에서 다시 열어 **진행 중이던 방 다시 열기**를 누르면 이어집니다.
- 클래식 버전 방과 새 버전 방은 서로 섞이지 않습니다.

## 단축키

| 키 | 동작 |
|---|---|
| `1`–`4` | 보기 선택 |
| `Q` `W` `E` `R` | 과목 선택 (공통 / 미적분 / 확통 / 기하) |
| `1` / `2` | 난이도 선택 (기본 / 심화) |
| `1`–`3` | 증강 선택 |
| `←` `→` | 조준 5° (Shift: 15°) |
| `V` | 플레이어 시점 ↔ 전체 보기 |
